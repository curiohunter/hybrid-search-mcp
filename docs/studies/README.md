# studies — 외부 조사 기록

계획서(`docs/plans/`)와 인계 문서(`docs/handoff/`)가 **우리가 무엇을 했는지**를 적는다면,
여기는 **밖에서 무엇을 알아냈고 그게 우리에게 무엇이었는지**를 적는다.

## 왜 따로 두나

조사 결과가 계획서 안에 섞이면 두 가지를 잃는다.

1. **조사는 계획보다 오래 산다.** 계획은 실행되면 아카이브되지만 "이 논문이 무엇을
   주장하고 우리 코퍼스에서 어떻게 됐나"는 다음 라운드에도 그대로 쓰인다.
2. **재조사를 막는다.** 이 라인은 같은 주제를 여러 번 조사했다(2026-09-01 3축 조사,
   2026-09-08 입도 조사, 2026-09-11 융합 조사). 어디를 이미 팠는지 한눈에 보여야 한다.

## 규칙

- **처방까지 적는다.** 요약만 있는 문서는 다음 사람이 다시 읽게 만든다.
  "그래서 우리는 무엇을 했고 무엇이 나왔나"가 없으면 미완성이다.
- **반증도 적는다.** 문헌이 권한 것을 재봤는데 우리 코퍼스에서 졌다면 그게 가장
  값진 항목이다. 다음 사람이 같은 것을 다시 만들지 않는다.
- **코퍼스를 인용하지 않는다.** 이 레포는 public이다 — 지표·ID·구조만 적는다
  (`CLAUDE.md` 공개물 규칙).
- 파일명은 `YYYY-MM-DD-주제.md`.
